## 🚀 Projects

### [LearnQuest](https://github.com/real-yahya/LearnQuest)
Full-stack gamified e-learning platform built with Java Spring Boot and MySQL as part of a 9-person Agile team. Contributed the login page frontend and the course progress bar feature — allowing users to visually track how far they've completed a course.
`Java` `Spring Boot` `MySQL` `Spring Security` `Thymeleaf` `Gradle`

### [FleetManager](https://github.com/real-yahya/FleetManager)
Full-stack fleet management web app built with the MERN stack and Docker. Tracks company vehicles with live data including mileage, lease status, and fuel levels. Features CRUD operations, advanced search/filter, and a responsive React interface.
`React` `Node.js` `MongoDB` `Express.js` `Docker`

### [LLM-Controlled Robot Car](https://github.com/real-yahya/LLM-Controlled-Robot-Car)
Integrated OpenAI's LLM with ROS2 on Ubuntu to build a robot car simulation that converts natural language and image prompts into real-time movement commands. Achieved 2.7s average response latency with a Python-based GUI-to-LLM pipeline.
`Python` `ROS2` `Ubuntu` `JavaScript`

### Cloud-Hosted Whiteboard
Architected a scalable multi-node AWS environment (EC2 + EKS + ELB) with Docker containerisation and DynamoDB state replication for real-time multi-user collaboration. Diagnosed and resolved a critical websocket consistency bug by implementing sticky-session routing at the load balancer.
`AWS` `Docker` `Kubernetes` `DynamoDB`
